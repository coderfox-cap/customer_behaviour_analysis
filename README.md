# customer_behaviour_analysis
Customer Shopping Behavior Analysis  This project focuses on analyzing customer purchasing behavior using a dataset of over 3,900 retail transactions to extract meaningful business insights. The goal was to understand customer spending patterns, product preferences, subscription behavior, and the impact of discounts on sales performance

📌 Overview

This project focuses on analyzing customer shopping behavior using retail transaction data. The goal is to uncover insights about customer spending patterns, product preferences, subscription behavior, and the impact of discounts. The project combines Python, SQL (PostgreSQL), Power BI, and Gamma to deliver clean analysis, business insights, and professional reports.

📁 Dataset

Source: Retail transactional dataset
Records: 3,900+ transactions
Features include:
Customer details (Age, Gender, Location, Subscription Status)
Purchase information (Item, Category, Amount, Season, Size, Color)
Behavioral data (Discounts, Promo codes, Reviews, Shipping type, Purchase frequency)
Missing Values: Present in the Review Rating column and handled during cleaning.

🛠 Tools & Technologies
Python – Data loading, cleaning, and exploratory analysis
Pandas & Matplotlib/Seaborn – Data handling and visualization
PostgreSQL – Running business-focused SQL queries
Power BI – Interactive dashboard development
Gamma – Report and presentation (PPT) creation
